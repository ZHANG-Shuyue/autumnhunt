# AutumnHunt 🌾

一个为 2026 届秋招准备的个人管理工具网站。当前为 **v0.2（Phase 2）**：从展示骨架升级为本地可用的 CRUD 工具。

## 项目介绍

AutumnHunt 用于统一管理秋招全流程：
- 公司库（调研、链接、截止时间）
- 投递追踪（看板/表格/日历）
- 面试记录（时间线/表格）
- 日历事件（系统自动同步 + 自定义事件）

## 技术栈

- React 18 + Vite + TypeScript
- Tailwind CSS + shadcn 风格组件
- React Router v6
- Zustand + `persist`（localStorage）
- react-hook-form + zod
- date-fns
- dnd-kit（看板拖拽）
- sonner（toast）

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 部署到 GitHub Pages

已配置：
- `vite.config.ts`：`base: '/autumnhunt/'`
- `package.json`：`deploy: gh-pages -d dist`

部署：

```bash
npm run build
npm run deploy
```

## Phase 2 已完成功能

### 1) 完整 CRUD（localStorage 持久化）
- 公司库：增删改查 + 搜索 + 行业筛选 + 状态筛选 + 排序
- 投递追踪：增删改查 + 看板拖拽改状态 + 表格视图 + 日历事件联动
- 面试记录：增删改查 + 时间线/表格 + 筛选（全部/即将到来/已完成）
- 所有删除均二次确认
- 表单校验：react-hook-form + zod，失焦校验

### 2) 日历模块 `/calendar`
- 月视图 + 时间线视图切换
- 支持新建/编辑/删除自定义事件
- 支持事件类型筛选、系统自动事件显示开关
- 支持手动「同步」按钮刷新

### 3) 自动联动同步
系统自动生成并同步以下事件：
- 投递日期 → `投递`
- 笔试日期 → `笔试`
- 面试时间 → `面试`
- 公司截止日期 → `截止`

自动事件带 `isAutoGenerated=true`，在 UI 中标记为系统同步。

### 4) Dashboard 实时化
- 统计卡由真实 store 数据驱动
- 今日新增公司、近期面试、今日待办均使用真实数据
- 侧边栏“日历”带今日待办数字徽标

## 数据持久化说明

所有核心数据均通过 Zustand persist 存储在 localStorage：
- `autumnhunt-companies`
- `autumnhunt-applications`
- `autumnhunt-interviews`
- `autumnhunt-calendar`

每个 store 使用 `version: 1`，为后续迁移预留版本能力。
